# 大三和弦练习

## 和弦结构

大三和弦由**根音 + 大三度 + 纯五度**构成。

以 C 大调为例：**C - E - G**

---

## 练习方法

按五度圈顺时针方向（C → G → D → A → E → B → F# → Db → Ab → Eb → Bb → F），每个调执行以下步骤：

| 步骤 | 练习内容 | 示例（C 大调） |
|------|---------|--------------|
| ① | **调内 I 级原位大三和弦** | C - E - G |
| ② | **第一转位**（三音在低音） | E - G - C |
| ③ | **第二转位**（五音在低音） | G - C - E |
| ④ | **琶音上下行**（两个八度） | C → E → G → C → G → E → C |
| ⑤ | **柱式和弦连接**（I → IV → V → I） | C → F → G → C |

> **练习要点**：每个转位弹稳后再切换，手腕放松；琶音注意拇指穿指与中指/无名指跨指的衔接。

---

## 各调大三和弦速查

| 调 | I 级 | 构成音 |
|----|------|--------|
| C | C | C - E - G |
| G | G | G - B - D |
| D | D | D - F# - A |
| A | A | A - C# - E |
| E | E | E - G# - B |
| B | B | B - D# - F# |
| F# / Gb | F# | F# - A# - C# |
| Db | Db | Db - F - Ab |
| Ab | Ab | Ab - C - Eb |
| Eb | Eb | Eb - G - Bb |
| Bb | Bb | Bb - D - F |
| F | F | F - A - C |
