# 加九音和弦练习

## 和弦结构

加九音和弦在大三/小三和弦基础上**增加大九度音（即大二度的高八度）**，**不含七音**：

- **add9**：根音 + 大三度 + 纯五度 + 大九度，如 C - E - G - D
- **m(add9)**：根音 + 小三度 + 纯五度 + 大九度，如 C - Eb - G - D

> **注意区分 add9 与 9 和弦**：add9 没有七音，声音清澈开放；9 和弦（如 C9）必有属七音（Bb），听感更"爵士"。

---

## 练习方法

按五度圈顺时针方向，每个调执行以下步骤：

| 步骤 | 练习内容 |
|------|---------|
| ① | **原位 add9 柱式和弦**：右手五指分配（1-2-3-5 或 1-2-4-5 根据手型） |
| ② | **琶音**：根 → 3 → 5 → 9 → 5 → 3 → 根（上下行） |
| ③ | **和弦连接**：I(add9) → IV(add9) → V(add9) → I(add9) |
| ④ | **色彩对比**：同一调内交替弹奏大三和弦 → add9 → m(add9)，感受九音对和弦色彩的改变 |

> **练习要点**：九音与根音形成大二度碰撞，是 add9 的核心色彩。柱式弹奏时注意让九音在旋律位置突出，不要被其他音淹没。

## 各调 add9 速查

| 调 | add9 | 构成音 |
|----|------|--------|
| C | C(add9) | C - E - G - D |
| G | G(add9) | G - B - D - A |
| D | D(add9) | D - F# - A - E |
| A | A(add9) | A - C# - E - B |
| E | E(add9) | E - G# - B - F# |
| B | B(add9) | B - D# - F# - C# |
| F# | F#(add9) | F# - A# - C# - G# |
| Db | Db(add9) | Db - F - Ab - Eb |
| Ab | Ab(add9) | Ab - C - Eb - Bb |
| Eb | Eb(add9) | Eb - G - Bb - F |
| Bb | Bb(add9) | Bb - D - F - C |
| F | F(add9) | F - A - C - G |
