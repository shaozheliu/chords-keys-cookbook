# 小三和弦练习

## 和弦结构

小三和弦由**根音 + 小三度 + 纯五度**构成。

以 C 小调为例：**C - Eb - G**

---

## 练习方法

按五度圈顺时针方向，每个调执行以下步骤：

| 步骤 | 练习内容 | 示例（C 小调） |
|------|---------|--------------|
| ① | **调内 i 级原位小三和弦** | C - Eb - G |
| ② | **第一转位**（三音在低音） | Eb - G - C |
| ③ | **第二转位**（五音在低音） | G - C - Eb |
| ④ | **琶音上下行**（两个八度） | C → Eb → G → C → G → Eb → C |
| ⑤ | **柱式和弦连接**（i → iv → V → i） | Cm → Fm → G → Cm |

> **练习要点**：注意小三度与大三度的指距差异；小调 iv-V-i 连接时，V 级用大三和弦（和声小调升 VII 级），体会大 V 和弦带来的紧张感与解决到 i 的满足感。
