# 挂留和弦练习

## 和弦结构

挂留和弦用二度或四度音**替代三度音**，形成悬而未决的色彩：

- **sus2**：根音 + 大二度 + 纯五度，如 C - D - G
- **sus4**：根音 + 纯四度 + 纯五度，如 C - F - G

---

## 练习方法

按五度圈顺时针方向，每个调执行以下步骤：

| 步骤 | 练习内容 |
|------|---------|
| ① | **sus4 → 大三和弦 解决**：感受四度音下行到三度音的拉力 |
| ② | **sus2 → 大三和弦 解决**：感受二度音上行到三度音的拉力 |
| ③ | **sus4 ↔ sus2 交替**：保持根音与五音不变，只移动中间音（经典现代 worship / pop 手法） |
| ④ | **琶音上行**：sus2（根-2-5-根）/ sus4（根-4-5-根） |

> **练习要点**：重点体会 sus 和弦"悬空感"与解决到三和弦"落定感"的对比，这是挂留和弦的核心表现力来源。

---

## 各调 sus4 / sus2 速查

| 调 | sus4 | sus2 |
|----|------|------|
| C | C - F - G | C - D - G |
| G | G - C - D | G - A - D |
| D | D - G - A | D - E - A |
| A | A - D - E | A - B - E |
| E | E - A - B | E - F# - B |
| B | B - E - F# | B - C# - F# |
| F# | F# - B - C# | F# - G# - C# |
| Db | Db - Gb - Ab | Db - Eb - Ab |
| Ab | Ab - Db - Eb | Ab - Bb - Eb |
| Eb | Eb - Ab - Bb | Eb - F - Bb |
| Bb | Bb - Eb - F | Bb - C - F |
| F | F - Bb - C | F - G - C |
