# 六和弦与六九和弦练习

## 和弦结构

- **大六和弦（6）**：根音 + 大三度 + 纯五度 + 大六度，如 C - E - G - A
- **小六和弦（m6）**：根音 + 小三度 + 纯五度 + 大六度，如 C - Eb - G - A
- **六九和弦（69）**：根音 + 大三度 + 纯五度 + 大六度 + 大九度，如 C - E - G - A - D

> 六和弦有一种温暖、怀旧的色彩，是爵士 ballad 和 bossa nova 的常客；69 和弦叠加了九音的开放感，常用于乐曲的结束和弦（tonic chord）。

---

## 练习方法

按五度圈顺时针方向，每个调执行以下步骤：

| 步骤 | 练习内容 |
|------|---------|
| ① | **大六和弦 柱式 + 琶音**：右手 1-2-4-5 指位，琶音上下行两个八度 |
| ② | **小六和弦 柱式 + 琶音**：感受小调 + 大六度的独特色彩（介于忧伤与温暖之间） |
| ③ | **69 和弦 柱式**：五指不够时可双手分配 —— 左手根-5，右手 3-6-9 |
| ④ | **爵士终止式**：I6 → ii7 → V7 → I69（经典爵士收束方式） |

> **练习要点**：六度音与大三度形成纯四度（C6 中 E-A），是三全音之外另一重要的和弦色彩音程。69 和弦中六度与九度的叠加使声部更丰富，适合用琶音体会每个音的色彩贡献。
