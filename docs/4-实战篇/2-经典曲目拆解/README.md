## 拆解维度说明

每首曲目统一按以下五个维度拆解，便于横向对比与刻意练习：

1. **曲目信息**：调性、拍号、速度、难度与核心难点。
2. **和弦进行分析**：按段落（主歌 / 副歌）标注级数与功能。
3. **段落拆解**：分句拆解手型、声部排列与转位选择。
4. **伴奏手法**：主歌 / 副歌的织体差异与情绪推进。
5. **练习要点**：从单句到整曲的分层练习路径。
